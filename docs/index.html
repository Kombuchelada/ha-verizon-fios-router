Verizon Fios Router for Home Assistant

A HACS custom integration for the Verizon Fios CHR30A router. CR1000A / CR1000B may work, unverified.

Verizon's Fios routers have no SNMP, SSH or public API. This integration reads the router through the same local JSON API its admin web page uses, and brings it into Home Assistant:

  • WAN up/down, public IPv4 and IPv6
  • Per-port link, negotiated speed, error and discard counters
  • WAN download/upload throughput and hourly/daily data usage
  • Active devices, a new_device event when an unknown MAC joins, and per-device trackers
  • Switches for guest Wi-Fi, UPnP and per-device internet block; a reboot button
  • Last boot, firmware version and firmware-upgrade-in-progress

Local polling only: no cloud and no Verizon account. It never calls the router's factory-reset, firmware or backup endpoints.

Install and documentation on GitHub

Install with HACS: add https://github.com/Kombuchelada/ha-verizon-fios-router as a custom repository (type Integration), download Verizon Fios Router, restart, then add it under Settings → Devices & services. Requires Home Assistant 2026.8 or newer.
